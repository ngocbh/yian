# yian (Python, retired)

**Python yian is retired and no longer maintained.** 0.0.4 is the last release on PyPI; it is
the 0.0.3 code with this notice.

yian now ships as the npm package [`@ngocbh/yian`](https://www.npmjs.com/package/@ngocbh/yian),
written in TypeScript (Node >= 22.18 or Bun >= 1.4):

```
npm install @ngocbh/yian
```

To run it without installing, use `npx @ngocbh/yian` (plain `npx yian` fetches an unrelated package).

Docs: https://yian.readthedocs.io · Source: https://github.com/ngocbh/yian
